POST/notesCreate Note

Do not send user_id. Unknown fields are rejected.

Request body

FieldRequiredRule
titleyes1–200 characters after trimming
contentnodefaults to "", max 50,000
source_typenodefaults to manual, 1–50 characters

Responses

201 The saved note, including created_at and updated_at.

{
  "id": 1, "user_id": 1, "title": "Binary search trees",
  "content": "Left < parent < right.", "source_type": "manual",
  "created_at": "2026-10-24T03:19:33.030860Z",
  "updated_at": "2026-10-24T03:19:33.030860Z"
}

422 Invalid input. The message names the field.

GET/tasksList Tasks

Plain array of the dev user's tasks, newest first. No query parameters. limit, offset, and status are reserved for later.

Responses

200

[
  {
    "id": 1, "user_id": 1, "title": "Finish problem set 4",
    "due_date": "2026-10-30", "status": "todo",
    "created_at": "2026-10-24T03:19:33.068220Z",
    "updated_at": "2026-10-24T03:19:33.068220Z"
  }
]
POST/tasksCreate Task

Task fields are a proposal. Confirm them with Manny and Sebastian.

Request body

FieldRequiredRule
titleyes1–200 characters after trimming
due_datenoYYYY-MM-DD. Omit it for no due date.
statusnotodo or done. Defaults to todo.

Responses

201 The saved task.

{
  "id": 1, "user_id": 1, "title": "Finish problem set 4",
  "due_date": "2026-10-30", "status": "todo",
  "created_at": "2026-10-24T03:19:33.068220Z",
  "updated_at": "2026-10-24T03:19:33.068220Z"
}

422 Invalid input, including a status other than todo or done.

Schemas

NoteCreate, NoteOut, TaskCreate, TaskOut

NoteOut — id, user_id, title, content, source_type, created_at, updated_at

TaskOut — id, user_id, title, due_date, status, created_at, updated_at

On create, updated_at equals created_at. Lists stay plain arrays. Week 2 adds GET, PATCH, and DELETE on /notes/{id} and /tasks/{id}. Those routes are not in this page.
