# Contributing to Delphi

## Workflow

1. Pull the latest changes from main.
2. Create a feature branch.
3. Implement and test your changes.
4. Push your branch.
5. Open a pull request targeting main.
6. Wait for review before merging.

Do not push directly to main.

## Branch Naming

Use name/task-description.

Examples:
- ava/notes-api
- xitlaly/memory-retrieval
- maddie/markdown-import
- youssef/recommendations
- miya/frontend-skeleton
- manny/project-setup

## Pull Requests

Every PR should include:
- Summary of changes
- Testing instructions
- Related GitHub Issue
- Known limitations or blockers

Manny coordinates reviews and merges.

## Guidelines

- Never commit secrets or real .env files.
- Keep changes focused.
- Document new dependencies.
- Coordinate shared API and schema changes.
- Use synthetic sample data.
